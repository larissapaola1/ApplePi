# Historical public-replica record

These documents are preserved snapshots, not current execution instructions or eligibility claims.
In particular, the original methodology's statement that October evaluation was "after the freeze"
describes its own replica narrative; it does not establish an official submission freeze.
See ../PROVENANCE.md and ../METHODOLOGY.md for the current disclosure and official-data model.

The YAML snapshots are extracted from Git commit 111b489. Their previous-day edge setting is false.
Current official-data final/E6 configs use true. Keeping both records avoids silently attributing
historical replica scores to the edited current configurations. Raw historical run logs may not
be present, so preservation of these records alone does not independently verify every claim.
